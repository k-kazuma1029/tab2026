# The Authentic Baseball 2026（TAB 2026）

プロ野球ペナントシミュレーション。球団の監督として、采配・育成・補強・経営を行います。

## 遊び方

### Android
[Releases](https://github.com/k-kazuma1029/tab2026/releases) から最新の `TAB2026.apk` をダウンロードしてインストールしてください。
（初回は「提供元不明のアプリ」のインストール許可が必要です）

### iPhone / iPad（PWA）
1. Safari で https://k-kazuma1029.github.io/tab2026/ を開く
2. 共有ボタン →「ホーム画面に追加」
3. ホーム画面の「TAB 2026」から起動

セーブデータはその端末の中に保存されます（Android と iPhone の間では共有されません）。
大事なデータは、設定画面の「バックアップを書き出す」で保存しておくと安心です。
